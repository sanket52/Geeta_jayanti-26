# श्रीमद्भगवद्गीता जयंती महोत्सव 2026

A modern digital platform designed to celebrate **Geeta Jayanti Mahotsav 2026**, providing online student registration, Bhagavad Gita competitions, examination facilities, and an administrative dashboard.

## 🌐 About the Project

Geeta Jayanti Mahotsav is a digital platform developed to manage and organize online competitions and educational activities for students.

The platform allows students to register, participate in competitions, submit their work, attend online examinations, and track their participation.

**Event Date:** 20 December 2026

## ✨ Features

- **Student Registration:** Online registration with personal and academic details.
- **Authentication:** Secure login and registration with email OTP and Google authentication.
- **Student Dashboard:** Personalized dashboard to manage registration and competition activities.
- **Online Examination:** Timed examinations with automatic submission and evaluation.
- **Competition Management:** Support for multiple competition categories.
- **Video Submission:** Upload competition videos and other required documents.
- **Quiz Module:** Interactive quizzes with automatic result calculation.
- **Admin Dashboard:** Manage students, registrations, submissions, and examination results.
- **Student Support:** FAQ chatbot and support information.
- **Responsive Design:** Accessible across desktop, tablet, and mobile devices.

## 🏆 Competition Categories

1. Shlok Uccharan Competition
2. Rashtriya Geet Quiz Competition
3. Digital Bhashan Competition
4. Drawing Competition

## 🛠️ Technology Stack

- **Frontend:** Next.js / React.js
- **Styling:** Tailwind CSS
- **Backend & Database:** Supabase
- **Authentication:** Supabase Auth / Google OAuth
- **Storage:** Supabase Storage
- **Deployment:** Vercel
- **Version Control:** Git & GitHub

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/sanket52/Geeta_jayanti-26.git
```

### 2. Navigate to the Project

```bash
cd Geeta_jayanti-26
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env.local` file in the root directory and add your required configuration:

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
```

Never commit private API keys, service-role keys, or secrets to GitHub.

### 5. Start the Development Server

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```
